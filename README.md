# RoboPetCare

RoboPetCare connects with mobile apps using robotic devices. By monitoring and analyzing the behavior of pets, it can identify the health status of the pets. It alerts the pet owners when abnormal behaviors occur. At the same time, it stores the pet's behavior logs. Combined with the pet's physiological information entered by the pet owner in the app, it generates personalized feeding plan suggestions.

## Project Structure

- **`APP`** – The main software component of this prototype, covering behavior recognition, pet information entry, AI assistant, personalized feeding plan generation, and community functions. For detailed deployment instructions, please refer to the `README` file inside this folder.

- **`3D-Model`** – The 3D printing modeling files for this product, representing the product appearance and the shell that matches the camera module.

- **`Flash firmware&Debugging and Running`** – Contains the files that need to be configured and burned for the hardware camera, as well as detailed usage instructions.

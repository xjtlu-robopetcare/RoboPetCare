RoboPetCare connects with mobile apps using robotic devices. By monitoring and analyzing the behavior of pets, it can identify the health status of the pets. It alerts the pet owners when abnormal behaviors occur. At the same time, it stores the pet's behavior logs. Combined with the pet's physiological information entered by the pet owner in the app, it generates personalized feeding plan suggestions.
The folder "APP" is the main software component of this prototype, covering behavior recognition, pet information entry, AI assistant, personalized feeding plan generation, and community functions. The detailed deployment method can be referred to in the README file within the file folder.
The folder "3D-Model" is the 3D printing modeling file for this product, which represents the appearance of the product and the shell that matches the camera module.
The folder "Flash firmware&Debugging and Running" contains the files that need to be configured and burned for the hardware camera, as well as the detailed usage methods.

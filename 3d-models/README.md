# 📁 3D Models for RoboPetCare Hardware Enclosure

This folder contains the **3D design files for the product’s hardware enclosure and structural parts**, created as part of the mechanical design phase. These models are for prototyping, visualization, and future 3D printing.

---

## 📄 File Overview
All files are related to the physical casing and mounting structure of our pet care device.

| Filename | Format | Purpose |
|---|---|---|
| `Battery_Base_Demo(Zoom1.25).STEP` | STEP | 3D model of the battery compartment base (editable CAD file) |
| `Cat_Paw_Body(Zoom1.25).zip` | ZIP | Compressed package of main enclosure assembly files |
| `Cat_Paw_Paw(Zoom1.25).stl` | STL | 3D-printable file of the paw-shaped component |
| `K230_Back_Cover.STEP` | STEP | CAD model of the device’s back cover |
| `K230_Front_Cover.STEP` | STEP | CAD model of the device’s front cover |

---

## 📌 Notes
- These are **hardware mechanical design files** only, not software code.
- STEP files are editable and can be opened in CAD software (Fusion 360, SolidWorks, etc.).
- STL files are ready for 3D printing.
- The ZIP file contains additional assembly details for the enclosure body.
